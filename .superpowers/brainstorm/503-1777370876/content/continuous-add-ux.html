How should continuous add work?

Currently: submit → palette closes → click + again. What should happen instead?

A

Input stays open — clears on submit

Type name → Enter → "Jane added ✓" flash → input clears, cursor stays focused → type next name → Enter → ...

Press Esc to close. Same command palette, no extra UI.

Pros

  • Zero extra clicks
  • Keyboard-only flow
  • Minimal change to existing palette

Cons

  • No way to set type per-contact during bulk add
B

Bulk-add panel — name + type per row

A persistent side panel or modal with a growing list: each row has [Name input] [Type dropdown] [Add]. Press Enter to append next row automatically.

Pros

  • Can assign type to each contact on the spot
  • See all contacts being added at once

Cons

  • More UI to build
  • More complex interaction
C

Quick-add stays open + type selector

Same fast input field, but adds a type toggle row below it (Employee / Investor / Co-founder / Partner / Vendor). Selected type persists across submits.

Type name → Enter → input clears → type next name → Enter → ...

Pros

  • Fast keyboard flow preserved
  • Can switch type between contacts

Cons

  • Type toggle adds visual noise to palette
