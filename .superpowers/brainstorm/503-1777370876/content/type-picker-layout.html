Type selector in the quick-add form — which layout?

Name input stays open after each submit. Type must be set per contact. How should the picker look?

A

Segmented pill row below name input

Add contact
Enter to add · Esc to close

Pros

  • All types visible at once
  • One click to switch

Cons

  • Wider palette needed
B

Inline dropdown next to name input

Add contact
Enter to add · Esc to close

Pros

  • Compact — fits existing palette width

Cons

  • Dropdown opens on click, slower than pills
C

Two-step: name → then type

Add contact — step 1 of 2
Enter → pick type next

Pros

  • Name field stays clean
  • Type step can show richer descriptions

Cons

  • Two Enter presses per contact — slower
