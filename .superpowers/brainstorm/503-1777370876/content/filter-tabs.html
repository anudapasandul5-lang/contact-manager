How should the new contact types appear in the filter bar?

Currently: All · Employees · Vendors. Where do Investors, Co-founders, Partners fit?

A

Flat row — all types at same level

All · Employees · Vendors · Investors · Co-founders · Partners

Pros

  • Simple, one click to filter
  • Matches current pattern

Cons

  • Row gets wide with 6 tabs
B

Two rows — People vs Business

Row 1: All · Employees · Investors · Co-founders · Partners

Row 2: Vendors (stays separate as it already has different card UI)

Pros

  • Groups person-contacts together
  • Vendors are fundamentally different entities

Cons

  • More complex filter UI
C

Flat row + dropdown overflow

All · Employees · Vendors · More ▾ (reveals Investors, Co-founders, Partners)

Pros

  • Row stays clean
  • New types discoverable via dropdown

Cons

  • Extra click to reach new types
  • More complexity to build
