Personal Operations Hub

A second brain for running multiple businesses solo — without dropping anything.

The problem

Running multiple businesses under one banner means juggling dozens of contacts, projects, follow-ups, and commitments — across ventures that don't share a system. Today this lives in scattered pieces: Notion, phone notes, head-storage, half-remembered intentions.

Lost context
Which contact was tied to which project, again?
Missed follow-ups
"I'll get back to you next week" — and forgot.
No workload view
Which business is starving this week?
Capture leaks
Ideas in shower, in car, in line — gone.

The solution

Extend the existing Mindmap app into a full operations hub. Tasks layer on top of the relationship graph. Workload visible across all businesses in one screen. Voice-capture from anywhere. Daily email at 7am.

The killer feature: workload through a relationship lens. The mindmap shows your network. Tasks reveal which parts of that network are getting attention — and which are rotting. No other tool does this.

Build timeline

6 phases. ~4–5 weeks full-time.

Week 1
Foundation — schema & API
Businesses table, junctions, tasks table (with subtasks + recurrence). REST endpoints. Backfill existing owned companies into businesses.
Week 2
Forecast & side panel
/forecast page with five date columns. Business filter chips. Mindmap nodes show their tasks in a side panel on click.
Week 3
Capture & reminders
Cmd+K global quick-add. iOS Shortcut for voice capture. Right-click on graph nodes → add task. 7am daily email digest.
Week 4
Swim lanes & overlay
Toggle forecast view to per-business swim lanes. Overdue overlay on mindmap (red rings). PWA — install on phone.
Week 5
Subtasks
Nested tasks. Drag to reparent. Recursive completion. Checklist view on each task.
Week 6
Recurring tasks
"Every Monday", "first of the month", "every 2 weeks". Generator spawns next instance on completion.

What changes for you

Daily
  • One screen shows today's load across all businesses.
  • Voice capture: "Hey Siri, add task…" — done.
  • 7am email tells you the day before coffee.
  • Cmd+K captures from anywhere in 2 seconds.
  • Click a contact → see their tasks instantly.
Weekly
  • Sunday review: see which business is starving.
  • Mindmap reveals contacts you've been ghosting.
  • Recurring tasks fire on their own — invoices, reviews, check-ins.
  • Inbox triage as morning ritual. Empty by 9am.
Strategic
  • One source of truth replaces Notion + phone + head.
  • Same network serves all 3 businesses without fragmenting.
  • Workload data drives decisions on which business to feed.
  • Reputation: stops dropping balls across ventures.

What this is — and isn't

● In scope
  • Tasks with due + defer dates
  • Forecast view + business swim lanes
  • Subtasks (nested) + recurring tasks
  • Mindmap integration (side panel, overlay, quick-add)
  • Voice capture via iOS Shortcut
  • Daily email digest at 7am
  • Installable PWA — works on phone
● Out of scope (v1)
  • CRM lead pipeline / deal stages
  • Tags (cut for simplicity)
  • Team collaboration / multi-user
  • Email integration (auto-task-from-email)
  • Native iOS / Android app
  • Accounting, billing, contracts
  • Marketing or lead-gen automation

Build approach

Extends the existing Mindmap codebase (Next.js + Supabase + React Flow). No platform migration. Same hosting, same auth, same database. New features layer on top of an already-working graph.
